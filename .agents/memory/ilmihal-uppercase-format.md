---
name: Ilmihal uppercase format
description: Preserving the intentional all-caps typography in early Ilmihal lessons across translations.
---

For Ilmihal Nivo 1 lessons 1–20, translation must preserve all-uppercase text nodes from the Bosnian source. This is content formatting, not a signal to leave Bosnian text untranslated.

**Why:** The lessons intentionally use all-caps typography. Translation models tend to normalize the result to sentence case, making the translated lesson visually inconsistent with its source.

**How to apply:** Translate the text normally, then uppercase the translated text only where the corresponding source text node consists entirely of cased uppercase letters. Do this node-by-node for HTML so Arabic text and other protected content remain unchanged.
